# phys4147-fall2026
Programming problems to accompany PHYS-4147 (Relativity) at GeorgiaTech in Fall 2026

To run these notebooks on Google Colab, follow these instructions
1) Go to https://colab.research.google.com
2) Click on "Upload Notebook"
3) Select "Github" in the menu on the left
4) Copy and paste the URL of this repository in search bar at the top.
5) Select the folder for the homework you are working on, and select the .ipynb notebook to open it on colab.
